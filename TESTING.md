# Проверка fun-student

```powershell
.\mvnw.cmd clean verify
Start-Process .\target\site\jacoco\index.html
```

В Linux и macOS выполните `./mvnw clean verify`. Требуется JDK 21. На этапе `verify` JaCoCo формирует отчёт и проверяет два порога покрытия Java-кода, по 75% для строк и ветвлений. Результаты отдельных тестов находятся в `target/surefire-reports`.

Интеграционные тесты запускают приложение на случайном HTTP-порту и используют отдельные H2-базы в памяти. Внешняя PostgreSQL для тестов не нужна.

## Результат сборки

13 ноября 2026 года на JDK 21 прошли все 24 теста. JaCoCo измерил покрытие 255 из 268 строк (95,15%) и 76 из 88 ветвлений (86,36%).

| Набор | Что проверяет |
| --- | --- |
| `StudentApiTest` | Поиск по имени, фамилии и ID, сортировка, пагинация, обработка `%` как обычного символа, карточка, CRUD, частичное обновление и проверка полей |
| `AccountApiTest` | Анонимный доступ к интерфейсу, вход, права ролей, CRUD учётных записей, применение обновлённых прав, старый токен после удаления и повторного создания записи, ответы 400/401/403/404/409 |
| `AppInitializerTest` | Проверка параметров первоначальной настройки, создание администратора с хешированным паролем, повторный запуск без перезаписи |
| `JwtServiceTest` | Чтение подписанных токенов, отклонение истёкших токенов и проверка ключа подписи |

## Сценарий демонстрации

1. Откройте автономный предпросмотр или запустите сервер с профилем `demo` по [README](README.md).
2. В роли администратора студентов создайте студента, найдите его по фамилии и ID, откройте карточку. Измените почту, сохраните, затем удалите запись с подтверждением.
3. Переключитесь на преподавателя. Просмотрите реестр и карточку студента. Кнопки редактирования и удаления доступны администратору студентов.
4. Перейдите в раздел учётных записей под `SUPER_ADMIN`. Создайте преподавателя, найдите его по почте и отфильтруйте список по роли. Измените набор ролей и проверьте его при следующем входе.
5. Включите тёмную тему, обновите страницу и проверьте сохранение темы. Повторите поиск и открытие карточки на узком экране.

Для проверки хранения данных запустите приложение с PostgreSQL, добавьте запись, перезапустите только приложение и найдите ту же запись по ID.
